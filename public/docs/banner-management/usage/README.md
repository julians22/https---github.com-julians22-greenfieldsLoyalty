# Membuat Banner Baru

- Masuk ke CRM website
- Pilih menu `Banner Management`
- Klik tombol `Create New` pada atas kanan table Banner
	
	![Create Banner](../../img/Pasted%20image%2020230725152813.png)
	
	Setelah form muncul anda dapat memasukkan detail banner yang di butuhkan.
	
    - Desktop Banner Image (Banner yang di tampilkan pada Layar Desktop)
    - Mobile Banner Image (Banner yang di tampilkan pada Layar Mobile)
	
	![Create Banner](../../img/Pasted%20image%2020230725152902.png)
	
- Setelah semua field reward terisi, Klik tombol `Create Banner` untuk menyimpan data.

---

# Mengubah Banner

- Masuk ke CRM website
- Pilih menu `Banner Management`
- Klik tombol `Edit` pada Kolom `Action / Tindakan` pada item banner yang ingin di ubah.
	
	![../../img/Pasted image 20230725155500.png](../../img/Pasted%20image%2020230725155500.png)
	
	Setelah form muncul anda dapat memasukkan detail banner yang di butuhkan untuk perubahan banner.
	
    - Desktop Banner Image (Banner yang di tampilkan pada Layar Desktop)
    - Mobile Banner Image (Banner yang di tampilkan pada Layar Mobile)
	![../../img/Pasted image 20230725155641.png](../../img/Pasted%20image%2020230725155641.png)

- Setelah semua field reward terisi, Klik tombol `Update Banner` untuk menyimpan perubahan data.
---

# Menghapus Banner

- Masuk ke CRM website
- Pilih menu `Banner Management`
- Klik tombol `Hapus` pada Kolom `Action / Tindakan` di item banner yang ingin di hapus.
	![../../img/Pasted image 20230725161859.png](../../img/Pasted%20image%2020230725161859.png)
	
- Klik tombol `Confirm Delete` pada prompt persetujuan untuk menghapus data.
	![../../img/Pasted image 20230725162703.png](../../img/Pasted%20image%2020230725162703.png)
