# Reward Management (Management Hadiah)

Manage data reward/hadiah yang tersedia di website. 
Pada module ini anda dapat membuat, mengubah, menghapus data Reward/Hadiah yang ingin di tampilkan di website.

Note: 
Silahkan login ke CRM website menggunakan akun superadmin.
Module ini hanya dapat di gunakan oleh Super Admin saja.
