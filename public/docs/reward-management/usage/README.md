# Membuat Reward (Hadiah) Baru

- Masuk ke CRM website
- Pilih menu `Reward Management`
- Klik tombol `Create New` pada atas kanan table Reward
	
	![Pasted image 20230724173808.png](Pasted%20image%2020230724173808.png)
	
	Setelah form muncul anda dapat memasukkan detail reward yang di butuhkan untuk halaman depan nantinya.
	
    - Reward Title (Judul Hadiah)
    - Reward Deskription (Deskripsi Hadiah)
    - Reward Point (Point Reward, jumlah point yang di butuhkan untuk menukar hadiah)
    - Reward Image (Gambar Hadiah) `rekomendasi ukuran 375 × 245 px`
    - Initial Stock
    - Publish (Status Reward) `Off`akan menjadi `Draft` sebalikan `On` akan menjadi `Publish`.
	
	![Pasted image 20230724174813.png](Pasted%20image%2020230724174813.png)
	
- Setelah semua field reward terisi, Klik tombol `Create Reward` untuk menyimpan data.

# Mengubah Data Reward (Hadiah)

- Masuk ke CRM website
- Pilih menu `Reward Management`
- Klik tombol `Edit` pada Kolom `Action / Tindakan` di item reward yang ingin di ubah.
	
	![Pasted image 20230725150930.png](../../Pasted%20image%2020230725150930.png)
	
	Setelah form muncul anda dapat memasukkan detail reward yang di butuhkan untuk perubahan reward.
	
    - Reward Title (Judul Hadiah)
    - Reward Deskription (Deskripsi Hadiah)
    - Reward Point (Point Reward, jumlah point yang di butuhkan untuk menukar hadiah)
    - Reward Image (Gambar Hadiah) `rekomendasi ukuran 375 × 245 px`
    - Initial Stock
    - Publish (Status Reward) `Off`akan menjadi `Draft` sebalikan `On` akan menjadi `Publish`.
	
	![Pasted image 20230725151438.png](../../Pasted%20image%2020230725151438.png)

- Setelah semua field reward terisi, Klik tombol `Update Reward` untuk menyimpan perubahan data.

# Menghapus Data Reward (Hadiah)

- Masuk ke CRM website
- Pilih menu `Reward Management`
- Klik tombol `Hapus` pada Kolom `Action / Tindakan` di item reward yang ingin di hapus.
	
	![Pasted image 20230725151644.png](../../Pasted%20image%2020230725151644.png)
	
- Klik tombol `Confirm Delete` pada prompt persetujuan untuk menghapus data.
